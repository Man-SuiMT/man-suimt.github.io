📋 详细优化项目 (70+)

🖼️ 视觉效果与桌面

  • 调整为最佳性能（关闭所有动画、阴影、半透明）
  • 任务栏动画关闭
  • 拖动窗口时隐藏内容
  • 平滑屏幕字体边缘关闭
  • 启动时不恢复文件夹窗口

🌐 网络延迟降低

  • Nagle 算法禁用（所有网卡）
  • 网络节流关闭
  • TCP 自动调谐 Normal
  • DNS 缓存优化（正向86400秒，负向0）

⚙️ CPU / GPU 调度

  • GPU 优先级 8，调度类别 High
  • 核心停车禁用（CPMINCORES=100）
  • 处理器闲置状态禁用（仅台式）
  • 性能提升策略激进（PERFINCPOL=2）
  • 性能阈值锁定（不降频）
  • 处理器计划 → 程序（前台优先）
  • 处理器性能增强模式高性能

🔋 电源计划补充

  • PCIe ASPM 关闭
  • WiFi 强制最大性能
  • USB 选择性暂停禁用
  • 硬盘空闲关闭禁用
  • CPU 最小频率 100%（台式）
  • 电源方案：卓越性能

🖱️ 输入延迟

  • 鼠标数据队列缩减至 20
  • 键盘延迟 0，速度 31
  • 彻底关闭鼠标加速

🎥 显示与渲染

  • 全屏优化禁用（独占全屏模式）
  • 硬件加速 GPU 调度开启 (HwSchMode=2)
  • MPO 禁用 (OverlayTestMode=5)
  • Game Bar 完全关闭

💾 内存与磁盘

  • 页面文件固定 4096 MB
  • 休眠文件关闭
  • SysMain (Superfetch) 禁用
  • 大页内存 (Large Pages) 启用
  • 页面合并关闭
  • 内存压缩关闭（32 GB+ 自动执行）
  • NTFS 最后访问时间更新禁用
  • 8.3 短文件名生成禁用

🔐 封装防重置机制

✅ 三层保护，确保优化不丢失 ① 系统级策略与注册表（HKLM）永久驻留
② 部署后脚本 (SetupComplete.cmd) 在 OOBE 前自动重新应用电源、服务、注册表
③ 默认用户模板注入 (Default User)，新用户自动继承所有 HKCU 设置（鼠标、视觉效果等）

  • 系统未激活，需用户自行使用正版密钥或 KMS 激活。
